An operating system,

ForgeOS is a hand-written x86_64 operating system — real bootloader, real kernel, real shell. No Linux underneath, no borrowed init system. Just assembly, C, and a lot of long-mode page tables.

What's actually in the box

Nothing here is a wrapper around an existing kernel. Every layer was written from the ground up:

  • Bootloader — a 512-byte boot sector that reads the kernel off disk via BIOS INT13h, sets up a GDT, and drops into 32-bit protected mode.
  • Kernel — hand-rolled page tables take it the rest of the way into 64-bit long mode, where a small C kernel takes over.
  • Drivers — VGA text-mode output and a polling PS/2 keyboard driver, written directly against the hardware ports.
  • Shell — a command interpreter with a real (if temporary) in-RAM filesystem: ls, cat, write, rm, and more.
  • fpkg — a package manager designed around static file hosting, so publishing a package never requires a server.

Honest about what's missing

There's no GUI yet, no persistent disk filesystem, and no network stack — fpkg install is a stub until that lands. The docs page lays out the build order and why each piece comes next.

Rivet

Every OS needs a mascot. Ours is Rivet, an anvil with legs, because building an operating system is closer to blacksmithing than software engineering: you heat the same piece of metal a hundred times before it holds its shape.
